# The Robot Vacuum's Funniest Excuse

A robot vacuum's excuse for missing a spot: it claims it didn't miss the spot at all — the dust there unionized, and its suction refuses to cross a picket line. A one-line joke in the vacuum's own voice, built from its own world of dust and suction.

Run it: python3 main.py
